02 · AI DEVELOPMENT

AI 开发，从一个可用的作品开始。

选择一类任务，在自己的开发环境中完成，按实践清单验证结果。随后可以到社区分享经验，或去黑客松继续打磨。

01 · AI 应用

做一个文档问答助手

从一份公开资料开始，让用户提问、查看回答和来源。补上“找不到答案”、接口失败与等待状态。

完成标准可运行的演示、来源引用、至少 5 个验证问题。
展开实践步骤
  1. 选一份公开资料，写下 5 个真实问题和预期来源。
  2. 实现“提问 → 查找资料 → 回答并引用来源”的核心流程。
  3. 加入等待、无答案和接口失败状态，检查来源是否支持回答。
  4. 保存验证结果，提供启动说明和可运行的演示。
02 · AGENT

让 Agent 完成一个任务

做一个赛事整理助手：读取公开赛程，按兴趣筛选，输出包含日期、链接和筛选理由的简报。

完成标准清楚的任务边界、工具调用记录、失败时的处理办法。
展开实践步骤
  1. 明确一个需求，例如“找出未来两周的 Agent 黑客松”。
  2. 先用固定样例验证筛选，再低频读取公开赛事数据。
  3. 让 Agent 输出日期、官方链接和推荐理由，保留工具调用记录。
  4. 验证空结果、缺日期和读取失败，未知信息明确写出。
03 · VIBE CODING

把一个想法做成小应用

选一个每天会用到的工具，写清需求，使用 AI 辅助实现，再亲自检查交互、数据和异常情况。

完成标准可用的核心流程、验证记录、简短的使用说明。
展开实践步骤
  1. 选一个小工具，写清使用者、核心操作和完成标准。
  2. 把任务拆成短步骤，用 AI 辅助实现，每步都实际运行。
  3. 亲自验证正常输入、空输入、错误和手机交互。
  4. 写好使用说明，展示作品并记录一次改进。

带着作品，去找下一次实践机会。日历可按 Agent、Vibe Coding 和黑客松筛选、订阅。站内题目助手用于算法讲解与代码诊断；AI 项目由你在自己的开发环境中构建和验证。
