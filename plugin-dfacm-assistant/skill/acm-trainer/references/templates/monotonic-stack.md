# 模板：单调栈 / 单调队列

## 适用信号
- 每个元素找左/右第一个比它大/小的位置 → 单调栈（直方图最大矩形、柱状图视野）；
- 固定长度滑动窗口最值 → 单调队列（存下标，队头过期出队）。

## 复杂度
O(n)（每个元素至多入栈/出栈一次）。

## 常见坑
1. 栈/队列里存**下标**而不是值（要算距离/位置）；
2. 弹出条件中 `>=` 还是 `>` 取决于求"严格小"还是"小于等于"——求左边第一个**严格小于**时，相等的也要弹出；
3. 队头出队条件（下标滑出窗口）和单调维护（队尾弹出）是两件事，都要写。

## 模板（单调栈：每个数左边第一个比它小的下标，不存在为 0）

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, a[100010], l[100010];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    stack<int> stk;
    for (int i = 1; i <= n; i++) {
        while (!stk.empty() && a[stk.top()] >= a[i]) stk.pop();
        l[i] = stk.empty() ? 0 : stk.top();
        stk.push(i);
    }
    for (int i = 1; i <= n; i++) cout << l[i] << (i == n ? '\n' : ' ');
    return 0;
}
```

> 滑动窗口最值：同一思想改双端队列——入队前从队尾弹出所有比新元素大（求最小值时）的下标，再检查队头下标是否滑出窗口左界。
