# 模板：排序与贪心

## 适用信号
- 排序后按某种顺序选取能得到最优解（交换论证可证：任意交换相邻两个决策不更优）；
- 典型：区间调度（最多不相交区间）、排队打水、部分背包、反悔型贪心提示。

## 复杂度
O(n log n)（排序主导）。

## 常见坑
1. 贪心策略必须能给出交换论证，"感觉对"不行——先构造反例再写代码；
2. 自定义比较函数必须严格弱序（用 `<`，不要用 `<=`），否则 std::sort 可能越界崩溃；
3. 相等元素的处理顺序（按第二关键字排序）常常是隐藏关键。

区间调度的 `last` 初值只需不大于最小可能起点；当起点非负且判定用 `>=` 时，0 是合法初值。不同错误策略要给各自成立的反例，例如长度优先可被 `[0,3),[3,6),[2,4)` 反驳：先选最短中间区间只能取 1 个，选前两个可取 2 个。

## 两堆合并最小总代价

不限合并位置且权重非负时，每次合并最小两堆。证明把任意合并过程表示成满二叉树，总代价等于各原始权重乘叶深之和；最深叶有同深度兄弟，将最小两权放在这对叶上不增代价，再将两叶收缩成权重之和，归纳得到贪心。不能只说“替换一次合并为更小的堆”便跳过后续代价。

小根堆实现有 n 次初始 push、n−1 轮各 2 次 pop 和 1 次 push，即共 `4n−3` 次堆修改、每次 O(log n)，总 O(n log n)。堆里最多 n 个元素，计入底层容量；累加代价用 long long。该问题适用本贪心指导，代码按题面自实现。

## 模板（最多不相交区间）

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
pair<int,int> a[100010]; // {右端点, 左端点}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i].second >> a[i].first;
    sort(a + 1, a + n + 1); // 按右端点升序
    int cnt = 0, last = -2e9;
    for (int i = 1; i <= n; i++)
        if (a[i].second >= last) { cnt++; last = a[i].first; }
    cout << cnt << "\n";
    return 0;
}
```
