# 解题流程（F1）

OJ 的“查看题解”按钮也进入本流程；自动传入的题面与约束已在上下文中。`source: "oj"` 时输出结构按 [oj.md](oj.md)，下面的五段式用于普通聊天；分析与完整性检查仍照常执行。

## 触发
用户粘贴算法题面（题目描述 / 输入输出格式 / 数据范围 / 样例，允许部分缺失），或明确说"帮我解这道题"。

## 处理流程（严格按序执行）

先检查技能支持范围：交互题 / 提交答案题 / 依赖外部库不生成实现，说明限制与替代练习。以下五段式只适用于信息齐全的普通题。

默认交付是聊天中的完整题解。“代码生成”指生成 `cpp` 代码块；“输出前自检”指静态检查与手工推演。没有明确的保存或实际运行请求时，不写 `.cpp`、答案 Markdown、样例或可执行文件，不调用 `sample_test.py` 或编译器。工作区已有同题代码也不自动修改。明确要求保存时只做指定保存，要求运行时才做实际测试；题解正文仍完整输出到聊天。

1. **信息完整性检查**：复用本轮与上下文题面。缺少输入输出格式或数据范围时，**不生成代码**，列出缺失项清单一次性问全；补齐后继续。若下一轮仍缺必要信息，指出剩余缺项，可提供不依赖这些约束的概念说明，不用猜测的范围生成实现。
2. **题意提炼**：3-5 行复述，明确"给什么 → 求什么 → 约束是什么"。对题意有不确定处显式声明假设（遵守 SKILL.md 负面清单）。
3. **复杂度预算**：结合所有维度、总测试规模、时间和内存限制，写出最终实现的运算量与存储量估算。总时间包含初始化/读入，不仅是单次查询；空间按实际同时存活的输入、数组、缓存、容器容量与递归栈求和，区分总空间与辅助空间。例如 n=500 的三重循环约 1.25e8 次，不能仅凭 n≤500 判定可行；子集 DP 还需乘状态转移和计数维度。操作数与每次操作成本只相乘一次，算法名字不能证明代码采用了相应优化。即使有时限，未实测也只说明预算依据，不将比较/加法次数直接换成“1s 内充裕”；缺少限制时明确仍需结合评测环境验证。
4. **算法选型**：列出 1-2 个候选，写明选定理由与弃选原因；贪心给出使后续选择仍可行的交换论证，反例须确实反驳所指策略。命中 `references/templates/` 的考点时实际读取对应 1-2 个模板再改编；目录 glob 不等于已读模板。正文解释算法即可，不报告模板路径或技能执行过程。
5. **代码生成**：优先套模板骨架再按题意改编；未命中则自实现。代码风格必须符合 SKILL.md 全局规范。
6. **输出前自检**（逐项过）：头文件 / 类型（long long）/ 数组上限与 +10 余量 / 多测清空 / 边界（n=0、n=1、全相同、极值）/ 读入输出格式（是否取模、行尾空格、多组数据）。发现疑点 → 主动重生成，或在"易错点"段显式标注不确定项。

## 普通聊天输出格式（五段式，标题逐字固定）

**五个标题必须逐字输出，不加序号、不加任何后缀装饰**：`## 题意提炼`、`## 算法思路`、`## 参考实现（C++）`、`## 复杂度`、`## 易错点`。标题被测试脚本逐字解析，**禁止**写成 `## 一、题意提炼`、`## 算法思路（贪心）`、`## 三、参考实现` 之类的变体；考点/算法名称写进正文，不写进标题。

用户给出候选实现、要求自检时，将候选错误与修正依据写在“算法思路”或“易错点”正文，仍只输出这五个二级标题。输出前核对标题数量、顺序与“参考实现（C++）”的完整文字。

## 完整示例（few-shot，输出时模仿此结构与口吻）

**用户输入**：
> n 根原木，长度 a_1..a_n（1≤n≤1e5，1≤a_i≤1e9）。现在要把它们切成 k 段等长的小段（1≤k≤1e7），小段长度必须是正整数，可以有剩余废料。求小段长度的最大值；若连长度 1 都切不出 k 段，输出 0。
> 输入：第一行两个整数 n k；第二行 n 个整数表示 a_i。
> 输出：一个整数。

**期望输出**：

## 题意提炼
给定 n 根原木长度 a_i，把每根按需切成若干段等长小段（长度自选但全段一致，可剩余废料），要求共得到 k 段，最大化小段长度；无解输出 0。约束：n≤1e5，a_i≤1e9，k≤1e7。

## 算法思路
候选①二分答案：小段长度 x 的可行性关于 x 单调（x 越大，可切出的段数越少），check(x) = Σ⌊a_i/x⌋ ≥ k 可 O(n) 验证；总复杂度 O(n log max(a))，最多约 30n ≈ 3e6 次整除与累加。候选②枚举全部整数长度：最坏需要约 1e14 次检查操作，规模过大。选定二分答案。
关键步骤：1) 二分区间 [1, max(a)]；2) check 统计总段数与 k 比较；3) 无解输出 0。

## 参考实现（C++）
```cpp
#include <bits/stdc++.h>
using namespace std;

int n; long long k;
int a[100010];

bool check(long long x) {
    long long cnt = 0;
    for (int i = 1; i <= n; i++) cnt += a[i] / x;
    return cnt >= k;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> k;
    for (int i = 1; i <= n; i++) cin >> a[i];
    long long l = 1, r = *max_element(a + 1, a + n + 1), ans = 0;
    while (l <= r) {
        long long mid = (l + r) / 2;
        if (check(mid)) { ans = mid; l = mid + 1; }
        else r = mid - 1;
    }
    cout << ans << "\n";
    return 0;
}
```

## 复杂度
时间 O(n log max(a))，n=1e5、值域 1e9 时约 3e6 次整除与累加；空间 O(n)，数组约 0.4 MB。题面未给时限，此为规模估算，实际运行时间需结合评测环境验证。

## 易错点
1. Σ⌊a_i/x⌋ 最大可达 1e5×1e9=1e14，cnt 必须 long long（k 虽 ≤1e7 可 int，统一用 long long 更稳）；
2. 二分下界取 1 而非 0——check 内有除法，x=0 会除零；无解时 ans 保持初值 0 输出；
3. r 初值用 max(a) 而非 1e9，减少无效迭代（答案不可能超过最长原木）。
