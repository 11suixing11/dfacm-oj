# about 关于我们

**西南石油大学 ACM 团队**成立于 2017 年，由西南石油大学本科生组成，致力于程序设计竞赛。团队克服了成立初期经验不足的困难，自 2017 年以来已斩获**国奖 50 余项、省奖百余项**，荣获蓝桥杯优秀单位、CCCC 天梯赛优秀单位等称号。

本站 **SWPU OJ**（swpuacm.xyz）是团队官方在线评测平台，由新一届队员搭建维护：

- **4300+ 题库**：《信息学奥赛一本通》、蓝桥杯历年真题、Codeforces、LOJ、CSP-J/S 真题，以及 POJ 远程判题；
- **训练路线**：[一本通 396 题入门计划](/training/6abf5251aaa235606eedfb84)与[蓝桥杯 254 题备赛计划](/training/6abf552caaa235606eedfbee)，章节按顺序解锁；
- **训练赛**：周赛 / 月赛 / 校赛全程在站内进行，实时 RP 排名；
- **工作台与错题本**：练习进度一目了然，错题自动收录，补题闭环；
- **QQ 机器人播报**：比赛与 AC 动态实时播报到新生答疑群。

新生请先读讨论区置顶的[《ACM 新生入门须知》](/discuss/__DID_XUZHI__)，从这里开始你的登山之旅。
