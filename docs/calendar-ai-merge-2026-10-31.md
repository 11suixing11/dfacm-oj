# 赛事日历与 AI 赛讯合并发布记录

2026-10-31（北京时间），算法赛事日历与 AI 赛讯已合并到 [赛事日历](https://dfacm.website/calendar)。首次合并于 20:27 上线；手机布局修复于 20:39 完成部署验收，20:40 完成公网浏览器验收。当前线上资源为 `calendar-1.37.1.js` / `calendar-1.37.1.css`。

## 统一入口与行为

- 首页桌面、手机与 Hydro 导航统一使用“赛事日历”。清单同时收录算法赛、AI 赛与黑客松，按进行中、即将到来、日期待公布和已结束分组；往期默认折叠。
- 方向、赛事类型、Vibe Coding / Agent 兴趣、平台、状态、关键词和排序共用一套筛选。类型与兴趣分别取并集，跨条件取交集；浏览器页面、服务端清单、ICS 与 RSS 使用一致规则。JSON 继续提供完整赛事快照，兼容原 QQ 机器人。
- 增加主办方、奖金及币种、队伍数和兴趣信息。奖金按币种分组排序，不换算汇率。
- 跨来源相同赛事按稳定 ID 和规范官方 URL 合并；Codeforces ID 稳定，LeetCode `.com` / `.cn` 同场赛事去重。人工维护的不同赛事可以共用一份官方公告 URL，全部保留。
- 开赛时间未知时明确显示待公布；仅有结束时间的赛事可导出“赛事截止”，完全未知日期的赛事保留在 RSS。ICS 不编造开赛日期；原 QQ JSON 字段继续提供。
- 原 `/ai-contests`、`/ai-contests/`、`/ai-contests/calendar` 和旧 ICS / RSS 订阅返回 308，保留分类、兴趣和搜索并跳转到统一入口。`/ai-contests/api/*` 与 `/ai-contests/healthz` 保留给原采集服务。
- AI 采集服务继续运行，日历每 5 分钟读取其本机只读 API；失败后 1 分钟重试，上次成功数据最多回退 24 小时。原 Python 采集频率和数据库不变。
- 手机修复为日历外层添加专用样式，清除 Hydro 在手机上继承的左右负边距。公网浅色与深色页面在 320–1440 像素宽度下均无横向溢出。
