# UI 与训练流程交接 · 2026-10-23

本轮改进训练目录、工作台与题目返回流程：目录支持多条训练的查找和切换，工作台突出近期练习，评测后可回到原章节。根据用户反馈，保留原有深蓝和金色，并将原先偏重单条路线的预览扩展为完整目录。**2026-10-23 已按用户授权部署到线上**；[训练目录](https://dfacm.website/training) 和 [工作台](https://dfacm.website/workbench) 已可访问。本地改动尚未提交或推送，发布与备份信息见 [本次发布记录](ui-training-release-2026-10-23.md)。

## 页面与行为

- 首页、登录注册、工作台、错题本和原生主题恢复原有配色：浅色页面 `#f4f7fb`，深色页面 `#070d18`；主操作使用 `#2a5caa` 配白字，金色强调在明暗模式分别使用 `#8a6d1f` 和 `#e9c455`。徽标、山脊、代码演示区和蓝金进度条同步恢复。主要按钮高度至少 44px，长题名换行，窄屏纵向排列。
- 深色模式中将蓝色链接与按钮底色分开，使用 `#6fa3e0` 显示小字链接；金色背景配深蓝字，键盘焦点保持清晰。AC 继续使用成功绿，主题偏好与切换功能保留。
- 训练目录增加方向、搜索和“我加入的 / 已完成”筛选，作用于全部分页。每条路线显示简介、题量和进度，点击进入各自的原生详情页。新方向从名称前缀自动识别。
- 工作台首要区域显示最近练过的未完成路线、章节、进度及下一题；最多显示三条近期路线，同时给出全部已加入/已完成数量和“查看全部”入口。选择近期项前先分析所有已加入路线，避免已完成路线挤掉其他未完成路线。未加入路线时显示“选择训练路线”。
- 最近待补题先核对当前 AC 状态，再取最多 8 道。已通过的历史失败记录单独折叠，不再占用待补题名额。
- 登录首页隐藏新手指引，提供最近路线和工作台入口；恢复游客状态时恢复入门指引。
- 训练、题目、独立提交和本人普通评测页面增加训练导航。返回链接定位并展开原章节；WA 可返回修改，AC 后显示下一题，重判结束后重新核对进度。
- 工作台提供加载、失败重试和空状态。评测进度刷新有超时及重试；慢请求不会覆盖随后收到的新评测状态。

## 原生 Hydro 接入

对应版本为 Hydro **5.0.7** / ui-default **4.58.5**。导航从 `frontend/training.page.ts` 挂载，数据由 `training-hooks.ts` 与 `training-context.cjs` 提供。

目录数据由 `catalog-hooks.ts` 与 `catalog.cjs` 提供，在 `training/list` 钩子中追加 `category` / `view` 条件，因此原生计数与分页使用相同筛选。方向计数额外读取标题和 ID，并保留原生搜索和其他插件的查询限制。增强列表只输出当前页的信息；原生“已加入”侧栏依然可能加载其他已加入路线。

`frontend/catalog.js` 和 `catalog.css` 挂载到 `training_main`，保留原 GET 搜索表单、分页和创建训练入口。服务端补齐原模板使用的 `qs`，翻页保留搜索词、方向、个人状态和其他插件已有参数；即使目录计数失败，原生列表与分页仍可用。目录进度沿用 Hydro 的训练状态，工作台按当前题目 AC 状态计算进度。

训练上下文使用 `training` / `trainingNode` 查询参数，`tid` 保留给比赛。服务端核对登录权限、域、报名、章节解锁、题目可见性、评测归属，并遵循训练及题目的扩展访问钩子。查看其他人的训练进度、比赛、自测、Hack 和历史重判版本均不附加个人导航。

原模板、编辑器代码、提交字段、自测和评测 WebSocket 继续由 Hydro 管理。导航仅调整普通题目与评测链接，不使用全局最近路线缓存。自定义训练对比的 PJAX 替换会重新识别链接，并隐藏其他用户页面上的个人进度。

## 本地预览

先在仓库的 `plugin-dfacm-train` 目录运行 `npm ci`，随后在仓库根目录运行：

```bash
node scripts/preview.cjs
```

打开 <http://127.0.0.1:4173/workbench>。顶部状态选择器提供正常、新用户、加载失败、慢速加载和长题名示例。首页可切换游客与登录示例；进入下一题后，可以打开 WA、AC、评测中的结果示例并检查返回流程。

完整目录在 <http://127.0.0.1:4173/training>。2026-10-23 只读查看线上目录及第二页时，观察到以下 11 条路线；原生顺序将一本通放在第二页，新增方向筛选可以直接找到它。

| 方向 | 实际路线 | 规模 |
| --- | --- | --- |
| 入门 | 一本通基础 | 8 小节 / 396 题 |
| 进阶 | XCPC 专题训练 | 9 小节 / 108 题 |
| 蓝桥杯 | 真题训练 | 4 小节 / 253 题 |
| 专题 | 二分与枚举优化、贪心与构造、字符串、数学、数据结构、图论、动态规划、搜索与剪枝 | 每条 5 小节 / 32 题 |

`scripts/preview/catalog.cjs` 保存上述公开名称、ID 和规模；简介为本地简写，报名人数和个人进度均为合成示例，未复制当前账号的进度。样本包含 8 条已加入、1 条已完成，与工作台统计一致。默认按 10 条分页；可检查 `?view=enrolled`、`?view=completed` 和游客示例 `?member=0`。实际插件不写死这些 ID 或数量。

一本通保留完整的本地章节返回示例；其他路线详情显示自己的名称与规模，并明确提示未加载完整章节，不再显示一本通的章节或下一题。线上只查看了目录，没有通过训练详情访问触发进度更新。

工作台、错题本、首页和认证页使用仓库中实际页面；题库、题目及训练详情使用本地布局和固定数据。训练导航与线上使用同一份前端源代码。本地服务仅监听 `127.0.0.1`，所有非 GET/HEAD 请求返回 503，不写数据库、不发邮件、不提交判题。
