### A-4 `#4142` 乘法运算 —— 仍坏，且只能"重新定义"，不能"还原"

线上 4 个 `.out` 全部含 U+FFFD（1.out 8 个、2/3/4.out 各 14 个）：

```
1.out: "   5" / "\ufffd\ufffd 2" / "\ufffd\ufffd\ufffd\ufffd\ufffd\ufffd" / "  10"
2.out: "  25" / "\ufffd\ufffd40" / "……" / "  00" / "100" / "……" / "1000"
```

从字节形态可判断：原文件是 **GBK**，导入时按 UTF-8 解，全角 `×`（A1C1）和横线类字符
（A9A4 等）各 2 字节全部塌成 U+FFFD。**乘数/积/中间行都完好，只有 `×` 和横线坏了。**

- 还原不可能：横线到底是 3 个全角字符还是别的，已无从考证，且原参考解不可得。
- **可行修法（=10-08 报告的建议）**：改用纯 ASCII 重新定义竖式（`*` 与 `-`），
  同时改**题面样例 + 4 个 `.out`**，让题面与判题自洽；改完必须
  写一份参考解在站内远程评测 AC 一次，再宣布修好。
- 优先级：**低于 A-1/A-2**（只有 1 道题，且当前状态是"没人做"，不是"做了被误判"）。
