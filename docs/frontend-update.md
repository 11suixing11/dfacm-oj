# 新生前端体验优化

本次保留深蓝、品牌金、山脊和自托管展示字体，改进新生从首页进入训练的流程。没有更改认证接口、题目、训练配置或判题逻辑。

## 本地预览

在仓库根目录执行：

```bash
node scripts/preview.cjs
```

打开 `http://127.0.0.1:4173/` 查看首页，`/reg` 查看注册页，`/reg?tab=login` 查看验证码登录。可用 `PORT` 环境变量调整端口。服务仅监听本机。

预览不连接 Hydro、数据库或邮件服务。提交表单会明确提示未连接后端；题库、训练等后端页面显示本地预览说明，不会跳往线上冒充验证成功。

## 主要变化

- 首页：新增注册、入门路线、认识评测三个步骤；首屏直接可用，取消强制开场等待、持续粒子、视差和循环打字。评测演示改为主动点击，标明演示用途。
- 阅读：提高次要文字对比度，调整桌面与手机间距，保留地图并优化移动章节入口；遵循减少动态效果设置。
- 导航：移动菜单支持 Escape、焦点循环和切换桌面宽度后解除锁定；无需 JavaScript 仍可进入主要训练入口。
- 注册/登录：双栏引导布局、手机单栏、可显示密码、方向键切换标签、字段错误定位、数字验证码输入、及时倒计时和重复提交保护；沿用插件单一模板。
- 请求失败：断网、15 秒超时、非 JSON / 异常 JSON、HTTP 错误均显示反馈并恢复按钮。服务端错误文案仍由服务端决定。
- 题库主题：导航和表头统一为深蓝，保留 Hydro 原有明暗表面及状态色；改善表格字号、行距、代码块溢出和键盘焦点。
- 修复复制域名仍为旧 `bot.cd` 的问题，统一为 `swpuacm.xyz`。

## 部署文件

本地修改不会自动发布。部署时沿用 [现有部署流程](../deploy/deployment.md)：

1. `landing/index.html` 仍上传为独立自定义目录中的 `home.html`；不需要新增静态资源规则。
2. `/reg` 由 `plugin-swpu-regcode/reg.html` 提供，保留当前主分支的单一模板方案。插件启动时读取模板，更新后需按原部署流程重载插件。
3. 默认使用原生双主题（默认 light）与 `00-brand.css`，阅读和导航改进已同步到这一薄层；01—05 仅供旧版回退。安装脚本遇到既有品牌标记会跳过，因此更新前需备份并替换旧品牌块，同时维护静态产物和源包副本，详见 [主题说明](../theme/README.md)。

## 验证范围

- 推送前已移植到最新主分支，不携带旧后端；当前 7 项插件单元测试、页面接入与脚本语法检查通过。
- 浏览器覆盖 320、390、820、1440 像素布局；首页、注册、登录均无页面级横向溢出和脚本异常。

- 请求检查使用本机模拟响应，没有发送真实邮件或创建真实账户。完整邮件投递及真实 Hydro 登录仍需部署后验收。
